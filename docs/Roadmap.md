# Roadmap проекта Marcus

Фиксирует текущее состояние и план работ на MVP и Этап 2.

## Условные обозначения состояний
- **Done** — задача завершена, артефакты в репозитории.
- **In progress** — работа начата, требуется завершение.
- **Todo** — запланировано, ещё не стартовало.

| Архитектурное проектирование | `docs/Проектирование интернет-магазина Marcus (Next.js + Strapi).md` описывает доменную модель, интеграции и пайплайны | Done |
