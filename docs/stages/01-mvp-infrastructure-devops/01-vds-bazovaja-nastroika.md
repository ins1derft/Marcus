# VDS и базовая настройка

**Статус:** Done  
**Контекст:** `docker/`, `nginx/`, `certbot/` содержат серверную инфраструктуру.

## Цель
- Подготовить виртуальный сервер и системные зависимости для развёртывания приложений.

## Декомпозиция
1. Выбрать провайдера VDS, уточнить требования по CPU/RAM/диску и региону.
2. Развернуть сервер, задать имя хоста, настроить доступ по SSH (ключи, disable password).
3. Обновить систему, установить необходимые пакеты (docker, docker compose, monitoring agents).
4. Настроить пользователей и группы, обеспечить принцип наименьших прав.
5. Сформировать базовую структуру каталогов для проектов (`/srv/marcus`, `/var/log/marcus`).
6. Настроить firewall (ufw/iptables) и security hardening (fail2ban, SSHd конфиг).
7. Описать регламенты бэкапов системных конфигов и секретов.
8. Зафиксировать шаги и параметры в README/infra документации.

## Результаты
- Готовый сервер с предустановленным Docker и защищённым доступом для команды.

## Риски и допущения
- Изменение провайдера потребует повторения процедуры и переноса конфигов.
- Отсутствие мониторинга ресурсоёмкости усложнит диагностику проблем в проде.
