# Nginx reverse proxy

**Статус:** Done  
**Контекст:** `nginx/default.conf` проксирует фронтенд, Strapi и статику.

## Цель
- Настроить единый входной шлюз, обеспечивающий маршрутизацию трафика и базовую безопасность.

## Декомпозиция
1. Определить upstream-сервисы (Next.js, Strapi, статические ресурсы, health-check endpoints).
2. Настроить проксирование: location-блоки, headers, обработка ошибок, кэширование статики.
3. Включить gzip/brotli, безопасность заголовков (HSTS, CSP, X-Frame-Options).
4. Сконфигурировать веб-сокеты и long polling, если требуются.
5. Настроить ограничение размеров запросов и базовую защиту от DDoS/ботов (rate limiting).
6. Подготовить конфиг для dev/prod, убедиться в совместимости с Certbot.
7. Написать инструкции деплоя/релоада конфигов, проверить синтаксис (`nginx -t`).
8. Настроить логи и их ротацию, описать схему хранения/аналитики логов.

## Результаты
- Конфигурация Nginx, обеспечивающая стабильную работу фронта и CMS за обратным прокси.

## Риски и допущения
- Изменения в backend endpoints требуют актуализации правил проксирования.
- Отсутствие мониторинга доступности Nginx усложнит диагностику простоя.
