# Docker Compose dev/prod

**Статус:** Done  
**Контекст:** `docker/development.compose.yml` и `docker/production.compose.yml` описывают сервисы.

## Цель
- Стандартизировать запуск окружений разработки и продакшена через Docker Compose.

## Декомпозиция
1. Определить набор сервисов (frontend, strapi, postgres, redis, meilisearch, nginx).
2. Настроить `development.compose.yml`: тома для hot-reload, окружение разработчиков.
3. Настроить `production.compose.yml`: оптимизированные образы, сети, персистентные тома.
4. Описать стратегии сборки образов: Dockerfile, build args, мультистейдж.
5. Настроить `.env` шаблоны и переменные окружения для обоих сценариев.
6. Добавить healthchecks и restart policies соответствующие SLA.
7. Провести прогон `docker compose up` в обоих режимах, задокументировать шаги запуска/остановки.
8. Зафиксировать инструкции по обновлению сервисов и миграциям баз данных.

## Результаты
- Управляемые конфигурации Compose для локальной разработки и продакшена.

## Риски и допущения
- Несогласованность версий образов может привести к дрейфу окружений.
- Отсутствие автоматизации миграций баз данных нарушит CI/CD поток.
