# Компоненты и динамические зоны

**Статус:** Done  
**Контекст:** `strapi/src/components` реализует tiered price, SEO, медиа, адреса и другие компоненты.

## Цель
- Обеспечить переиспользуемые компоненты и динамические зоны для гибкой сборки контента.

## Декомпозиция
1. Сформировать список повторяющихся блоков (SEO, галереи, адреса, прайс-листы).
2. Создать компоненты в Strapi: поля, вложенные структуры, связи, интернационализация.
3. Определить динамические зоны для страниц, задокументировать правила использования.
4. Настроить отображение и превью компонентов в админке для редакторов.
5. Обновить API-схемы, чтобы фронтенд корректно обрабатывал динамические поля.
6. Покрыть компоненты тестовыми данными и демо-записями.
7. Обновить документацию, добавить примеры JSON для интеграций.
8. Провести ревью с командой фронтенда и контент-менеджерами.

## Результаты
- Набор компонент в Strapi обеспечивает гибкость контентных страниц и reuse блоков.

## Риски и допущения
- Сложные вложенные структуры увеличивают сложность фронтенд-рендера.
- Изменение структуры компонентов требует миграции данных и обновления API-клиентов.
