# S3/CDN провайдер

**Статус:** Done  
**Контекст:** `strapi/config/plugins.ts` настраивает `aws-s3`, использует `NEXT_PUBLIC_ASSET_HOST`.

## Цель
- Настроить хранение файлов в S3-совместимом хранилище и отдачу через CDN.

## Декомпозиция
1. Определить провайдера S3 (AWS, Yandex, Selectel) и создать бакеты/пользователей.
2. Настроить политики IAM: доступ только для нужных сервисов, ограничение прав.
3. Конфигурировать Strapi плагин `aws-s3`: ключи, регион, префиксы директорий.
4. Настроить CDN-домен и привязать к бакету, задать кэширование и invalidation правила.
5. Обновить переменные окружения (`S3_*`, `NEXT_PUBLIC_ASSET_HOST`) и шаблоны `.env`.
6. Протестировать загрузку/удаление файлов через админку Strapi и API.
7. Зафиксировать регламент по очистке и lifecycle (версии, архивация, TTL).
8. Обновить документацию и инструкции для фронтенда по работе с asset host.

## Результаты
- Медиа и статика отдаются через быстрый CDN, Strapi сохраняет файлы в управляемом хранилище.

## Риски и допущения
- Неправильные права доступа могут открыть публичный доступ к приватным файлам.
- Смена провайдера S3 требует обновления конфигов и миграции медиа.
