# Интеграции доставки

**Статус:** Todo  
**Контекст:** СДЭК, Деловые Линии, Яндекс.Доставка, виджет ПВЗ.

## Цель
- Подключить основные службы доставки и предоставить пользователю выбор способов и пунктов выдачи.

## Декомпозиция
1. Проанализировать API служб доставки: авторизация, расчёт тарифов, оформление заказов.
2. Реализовать слой интеграций (service adapters) для каждой компании, унифицировать интерфейсы.
3. Настроить кеширование тарифов и время жизни предложений.
4. Реализовать виджет выбора ПВЗ на фронтенде (встроенный или кастомный), обеспечить UX.
5. Обновить checkout: выбор доставки, расчёт стоимости, сроки, ограничения.
6. Настроить обработку статусов доставки и уведомления пользователя.
7. Организовать мониторинг и алёрты по сбоям в интеграциях.
8. Подготовить документацию для поддержки и инструкции по подключению новых служб.

## Контрольные точки
- Пользователь может выбрать доставку и оформить заказ с нужным провайдером.
- Статусы доставки актуализируются в CMS и отображаются клиенту.

## Риски и допущения
- Различия API потребуют дополнительного слоя абстракции.
- Недоступность сервисов доставки может блокировать оформление заказов без fallback.
