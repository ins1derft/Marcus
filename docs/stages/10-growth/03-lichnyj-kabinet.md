# Личный кабинет

**Статус:** Todo  
**Контекст:** История заказов, повторы, управление адресами.

## Цель
- Создать личный кабинет для клиентов, позволяющий просматривать заказы и управлять данными.

## Декомпозиция
1. Определить функциональный объём: профиль, история заказов, повторное оформление, адресная книга.
2. Реализовать аутентификацию/авторизацию (JWT, session, OAuth) и управление сессиями.
3. Спроектировать API и модели данных в Strapi для пользовательских сущностей.
4. Разработать UI личного кабинета: навигация, responsive, доступность.
5. Реализовать функции: просмотр деталей заказа, повтор заказа, скачивание документов, обновление профиля.
6. Настроить уведомления и подтверждения действий (email/SMS).
7. Добавить меры безопасности (2FA, ограничения по IP, логирование действий).
8. Написать тесты (unit, e2e) и провести UX-тестирование.
9. Документировать работу личного кабинета и требования к поддержке.

## Контрольные точки
- Пользователь с доступом видит полную историю заказов и может повторить заказ.
- Персональные данные защищены и соответствуют требованиям закона.

## Риски и допущения
- Сложность интеграции с существующей CRM может повлиять на сроки.
- Необходимость соответствия ФЗ-152 требует доп. проверки безопасности.
