# Интеграция «Моё дело»

**Статус:** Todo  
**Контекст:** Экспорт счетов и первичных документов из Strapi.

## Цель
- Автоматизировать передачу бухгалтерских данных в систему «Моё дело».

## Декомпозиция
1. Изучить API/форматы обмена «Моё дело» (REST, XML, CSV) и требования к авторизации.
2. Определить набор данных для экспорта (счета, накладные, данные клиентов).
3. Разработать модуль интеграции в backend: генерация документов, отправка, обработка ответов.
4. Настроить планировщик/триггеры на события заказа (создание, оплата, отгрузка).
5. Реализовать систему мониторинга и логирования обмена, обработку ошибок и ретраев.
6. Организовать хранение архивных копий отправленных документов.
7. Провести тестовый обмен с «Моё дело», получить подтверждение корректности данных.
8. Документировать процесс, включить инструкции для бухгалтерии.

## Контрольные точки
- Документы автоматически выгружаются и подтверждаются системой «Моё дело».
- Ошибки обмена фиксируются и оперативно устраняются.

## Риски и допущения
- Изменения API потребуют быстрой адаптации интеграции.
- Некорректная обработка персональных данных может повлечь юридические риски.
