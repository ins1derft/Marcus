# SEO-лендинги

**Статус:** Todo  
**Контекст:** Генерация страниц по фасетам и каноникал-сетка.

## Цель
- Создать масштабируемую систему SEO-страниц для привлечения органического трафика.

## Декомпозиция
1. Выбрать целевые фасеты/комбинации фильтров и утвердить стратегию с SEO-специалистом.
2. Настроить генерацию страниц (SSG/ISR) на основе данных Strapi/Meilisearch.
3. Реализовать шаблоны страниц: контентные блоки, FAQ, CTA, микроразметка.
4. Настроить canonical-сетку, чтобы избежать дублей и корректно распределить вес.
5. Реализовать sitemap для SEO-лендингов и автоматическое обновление при изменениях.
6. Подготовить систему A/B тестирования и мониторинга позиций.
7. Настроить аналитику трафика и конверсий (GA4, Search Console).
8. Документировать процесс запуска новых лендингов и критерии эффективности.

## Контрольные точки
- SEO-лендинги индексируются и приводят трафик.
- Каноникал и внутренняя перелинковка настроены корректно.

## Риски и допущения
- Избыточное количество лендингов без контента может привести к санкциям поисковиков.
- Неправильная каноникализация создаст проблемы с дублями страниц.
