# REST и бизнес-правила

**Статус:** Todo  
**Контекст:** Реализовать сервисы и валидаторы статусов, расчёта доставки.

## Цель
- Разработать программные интерфейсы и бизнес-логику для управления заказами и расчётом доставки.

## Декомпозиция
1. Сформировать API контракты: создание корзины, обновление позиций, оформление заказа, изменение статуса.
2. Реализовать сервисы в Strapi/Node: расчёт итоговой суммы, скидок, налогов.
3. Интегрировать расчёт доставки: внешние API, тарифные таблицы, обработка ошибок.
4. Настроить state machine статусов заказа, проверки на переходы и права доступа.
5. Добавить валидации входящих данных (MOQ, наличие, ограничения нанесения).
6. Реализовать webhooks/уведомления для событий (новый заказ, изменение статуса).
7. Написать unit и интеграционные тесты API.
8. Обновить документацию (Swagger/Postman) и инструкции для фронтенда.

## Контрольные точки
- API покрывает полный цикл заказа и валидирует бизнес-правила.
- Интеграции с доставкой проходят тестовые кейсы без ошибок.

## Риски и допущения
- Сложные тарифные модели доставки потребуют кеширования и оптимизации.
- Несинхронизированные правила между фронтом и backend приведут к ошибкам оформления.
