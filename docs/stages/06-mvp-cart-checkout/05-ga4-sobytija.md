# GA4 события

**Статус:** Todo  
**Контекст:** Требуется проброс `view_item`, `add_to_cart`, `begin_checkout`, `purchase`.

## Цель
- Настроить отслеживание ключевых e-commerce событий для аналитики и оптимизации воронки.

## Декомпозиция
1. Уточнить схему e-commerce событий GA4 и сопоставить с бизнес-атрибутами (id, name, price, quantity).
2. Определить точки генерации событий на фронтенде (PDP, корзина, checkout, финальный экран).
3. Реализовать отправку событий через GTM/gtag с корректной структурой данных.
4. Настроить события backend (если требуется) для подтверждения реальных заказов.
5. Провести тестирование в DebugView GA4, убедиться в корректности параметров.
6. Настроить пользовательские отчёты/дашборды для отслеживания конверсий.
7. Обновить политики consent/cookie, чтобы учитывать пользовательские согласия.
8. Документировать инструкцию по добавлению новых событий и ответственным ролям.

## Контрольные точки
- События фиксируются в GA4, данные совпадают с CMS/бэк-офисом.
- Есть дашборды, доступные маркетингу и продукту.

## Риски и допущения
- Неправильная структура событий приведёт к невозможности строить e-commerce отчёты.
- Без согласия пользователя события должны блокироваться во избежание нарушений.
