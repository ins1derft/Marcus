# Frontend корзины и checkout

**Статус:** Todo  
**Контекст:** Реализовать UX, хранение корзины и валидацию.

## Цель
- Создать интерфейс корзины и оформления заказа, обеспечивающий корректные данные и высокую конверсию.

## Декомпозиция
1. Проработать UX flow: корзина, шаги checkout (контакты, доставка, оплата, подтверждение).
2. Реализовать состояние корзины (client-side storage, SSR hydration, синхронизация с backend).
3. Настроить формы checkout: валидация, подсказки, маски ввода, сохранение промежуточных данных.
4. Интегрировать API backend: получение доступных способов доставки/оплаты, отправка заказа.
5. Добавить обработку ошибок (недоступность API, недействительные товары, пересчёт суммы).
6. Реализовать UX фичи: промокоды, апселлы, подтверждение заказа, редактирование адресов.
7. Настроить аналитические события (add_to_cart, begin_checkout, purchase/submit_quote).
8. Провести кросс-браузерное и адаптивное тестирование, покрыть критические сценарии e2e.
9. Документировать ответственность фронтенда и backend за хранение состояния и валидации.

## Контрольные точки
- Корзина сохраняется между сессиями и синхронизируется с backend.
- Checkout успешно завершает заказ в 95% случаев без ошибок.

## Риски и допущения
- Сложные сценарии доставки могут перегрузить UI без UX-исследований.
- Неконсистентность данных между фронтом и CMS приведёт к сбоям при оформлении.
