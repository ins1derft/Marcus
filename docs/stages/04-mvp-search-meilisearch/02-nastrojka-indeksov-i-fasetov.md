# Настройка индексов и фасетов

**Статус:** In progress  
**Контекст:** Активирован плагин Meilisearch, требуется описать правила выдачи и typo tolerance.

## Цель
- Оптимизировать структуру индексов, чтобы поиск отвечал бизнес-требованиям по релевантности и фильтрации.

## Декомпозиция
1. Согласовать с продуктом ключевые сценарии поиска: категории, бренды, атрибуты.
2. Определить структуру документов в индексе: поля для отображения, фильтрации, сортировки.
3. Настроить приоритеты релевантности (ranking rules, searchable attributes, filterable attributes).
4. Сконфигурировать typo tolerance, synonyms, stop words для RU/EN.
5. Реализовать логирование поисковых запросов для калибровки настроек.
6. Создать дашборд для ручной проверки relevance и сравнения с эталонными запросами.
7. Протестировать изменения на тестовом окружении, собрать обратную связь от бизнеса.
8. Задокументировать финальные настройки и процесс актуализации при расширении каталога.

## Контрольные точки
- По ключевым запросам обеспечена релевантная выдача и корректные фасеты.
- Настройки versioned и могут быть восстановлены при откате.

## Риски и допущения
- Избыточные фильтры приведут к раздуванию индекса и росту латентности.
- Отсутствие аналитики по запросам усложнит оптимизацию.
