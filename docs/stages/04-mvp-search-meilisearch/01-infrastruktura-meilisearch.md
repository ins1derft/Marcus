# Инфраструктура Meilisearch

**Статус:** Done  
**Контекст:** Сервис собран в Compose, переменные прокинуты в Strapi.

## Цель
- Поднять Meilisearch как сервис поиска с учётом безопасности и надёжности.

## Декомпозиция
1. Определить требования к ресурсам Meilisearch (RAM, CPU, диск) на основе объёма каталога.
2. Добавить сервис в Docker Compose: тома, сети, переменные окружения, healthchecks.
3. Настроить backup/restore стратегию для индексов.
4. Сконфигурировать API-ключи (master, search, admin), хранение секретов.
5. Обновить Strapi конфиги, чтобы подключаться к Meilisearch с нужными ключами.
6. Настроить мониторинг (uptime, latency, disk usage) и алёрты на деградацию.
7. Провести smoke-тесты: создание индекса, загрузка тестовых записей, поиск.
8. Документировать процесс деплоя и обновления версии Meilisearch.

## Результаты
- Meilisearch развёрнут и готов к использованию другими этапами (индексация, фронтенд).

## Риски и допущения
- Отсутствие резервных копий индексов усложнит восстановление после сбоев.
- Неверно настроенные ключи могут открыть доступ к админке посторонним.
