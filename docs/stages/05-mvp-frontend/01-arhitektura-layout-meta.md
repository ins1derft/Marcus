# 5.1 Архитектура, layout и meta

**Статус:** In progress  
**Контекст:** `src/app` и `next.config.ts` подготовлены, требуется внедрить типовой layout и мета-блоки.

## Цель
- Сформировать основу фронтенд-приложения: единый layout, head-метаданные, общие UI-компоненты.

## Декомпозиция
1. Зафиксировать дизайн-систему и схемы навигации: header, footer, меню, breadcrumb.
2. Реализовать базовый layout в `src/app/layout.tsx`: глобальные стили, провайдеры, шрифты.
3. Настроить генерацию meta-тегов (title, description, OG) с учётом `shared.seo` из Strapi.
4. Реализовать компоненты инфраструктуры: `AppShell`, `PageContainer`, `ViewportTracker`.
5. Настроить маршрутизацию и конфигурацию локализаций/динамических сегментов.
6. Подключить аналитические провайдеры (GTAG/Tag Manager) на уровне layout.
7. Организовать структуру директорий и правила импорта (module alias, barrel files).
8. Написать документацию по архитектуре фронта, checklist для новых страниц.

## Контрольные точки
- Layout переиспользуется всеми страницами, мета-данные формируются из CMS.
- Есть unit/snapshot тесты на базовую структуру.

## Риски и допущения
- Несогласованность с дизайном приведёт к постоянным переработкам компонентов.
- Отсутствие единого подхода к мета-данным нарушит SEO и аналитику.
