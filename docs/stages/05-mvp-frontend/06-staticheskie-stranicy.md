# 5.6 Статические страницы

**Статус:** Todo  
**Контекст:** Реализовать оферту, политику, контакты через CMS.

## Цель
- Опубликовать обязательные правовые и информационные страницы, управляемые из Strapi.

## Декомпозиция
1. Согласовать перечень страниц и содержание с юристом/заказчиком.
2. Создать соответствующие типы контента в Strapi (single types, локализации).
3. Реализовать шаблон статической страницы на фронтенде с адаптацией под разные типы контента.
4. Настроить маршруты `app/(legal)/...`, SEO теги, структуру хлебных крошек.
5. Подключить ISR/SSG и revalidate при обновлении контента в Strapi.
6. Добавить микроданные (Organization, ContactPoint) при необходимости.
7. Реализовать тесты отображения (unit/snapshot) и проверить доступность (a11y).
8. Документировать процесс обновления контента для контент-команды.

## Контрольные точки
- Все обязательные страницы доступны и обновляются из CMS.
- Соответствие юридическим требованиям подтверждено ответственным лицом.

## Риски и допущения
- Отсутствие процедуры ревизии контента ведёт к устареванию правовых текстов.
- Некорректные настройки SEO влияют на индексирование.
