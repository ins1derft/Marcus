# 5.3 Каталог (PLP)

**Статус:** Todo  
**Контекст:** Реализовать страницы категорий, фильтры, сортировки и интеграцию с Meilisearch.

## Цель
- Создать удобный каталог с быстрым поиском, фильтрами и сортировками для пользователей.

## Декомпозиция
1. Зафиксировать UX паттерны: сетка товаров, фильтры, пагинация, breadcrumbs.
2. Разработать компонент фильтров с поддержкой фасетов Meilisearch и сохранением состояния.
3. Реализовать поисковый запрос к Meilisearch: параметры фильтров, сортировки, paginated ответ.
4. Интегрировать Strapi данные для описаний категорий, SEO, баннеров.
5. Настроить SSR/ISR стратегию: prefetch популярных категорий, fallback для редких запросов.
6. Добавить обработку пустых результатов и рекомендаций.
7. Реализовать отслеживание аналитики (view_item_list, filter usage).
8. Написать тесты (unit для фильтров, e2e для навигации и поиска).
9. Документировать API контракт Meilisearch и структуру состояния фильтров.

## Контрольные точки
- Каталог корректно фильтрует и сортирует товары, производительность соответствует требованиям.
- Аналитика фиксирует взаимодействия пользователей.

## Риски и допущения
- Непродуманная структура состояния может усложнить поддержку и SSR.
- Ограничения Meilisearch по размеру ответа потребуют оптимизации запросов.
