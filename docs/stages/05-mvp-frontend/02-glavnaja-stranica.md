# 5.2 Главная страница

**Статус:** Todo  
**Контекст:** Сверстать блоки и подтянуть данные из Strapi.

## Цель
- Реализовать маркетинговую посадочную страницу, отражающую УТП и ключевые разделы каталога.

## Декомпозиция
1. Получить дизайн/прототип главной страницы, утвердить структуру блоков.
2. Определить источники данных в Strapi (баннеры, категории, коллекции, CTA-блоки).
3. Реализовать UI-компоненты блоков (hero, преимущества, подборки, отзывы, CTA).
4. Настроить ISR/SSG для главной страницы, определить частоту revalidate.
5. Интегрировать запросы к API: загрузка данных, обработка ошибок, состояния загрузки.
6. Добавить SEO-блоки: мета-теги, структурированные данные, OpenGraph.
7. Написать unit/visual тесты для ключевых компонентов, настроить скриншотные проверки.
8. Подготовить контент чек-лист и инструкцию для редакторов Strapi.

## Контрольные точки
- Главная страница отображается по дизайну и покрыта основными тестами.
- Данные корректно обновляются при изменениях в CMS.

## Риски и допущения
- Медленные API могут замедлить рендер без кеширования.
- Несогласованность контента и дизайна снижает конверсию.
