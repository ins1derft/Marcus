# 5.8 Оптимизация изображений

**Статус:** In progress  
**Контекст:** Использовать CDN, проверить web-perf.

## Цель
- Минимизировать вес изображений и обеспечить высокие показатели Core Web Vitals.

## Декомпозиция
1. Инвентаризировать источники изображений (Strapi медиа, CDN, статические ассеты).
2. Настроить Next.js Image Optimization с указанием `loader`, доменов и fallback.
3. Реализовать генерацию responsive изображений (srcset, размеры) для ключевых компонентов.
4. Настроить обработку форматов (webp/avif) и прогрессивную загрузку.
5. Проверить работу кэширования через CDN и задать политики хранения.
6. Провести Lighthouse/WebPageTest анализ, определить проблемные страницы.
7. Настроить мониторинг LCP/FID/CLS и регрессионные проверки в CI.
8. Обновить гайды для контент-команды: требования к размерам и формату загрузок.

## Контрольные точки
- Основные страницы достигают целевых LCP/CLS (<2.5s / <0.1).
- Изображения обслуживаются из CDN с корректным кешированием.

## Риски и допущения
- Неправильная конфигурация `next/image` может привести к ошибкам SSR.
- Отсутствие контроля контента (слишком большие исходники) снижает эффект оптимизации.
