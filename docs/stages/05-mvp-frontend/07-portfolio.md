# 5.7 Портфолио

**Статус:** Todo  
**Контекст:** Требуется реализовать раздел кейсов с выводом данных из Strapi.

## Цель
- Показать реализованные кейсы и повысить доверие потенциальных клиентов.

## Декомпозиция
1. Определить структуру данных кейсов в Strapi (title, описание, галерея, категория, результаты).
2. Разработать UI макет страницы списка портфолио и карточки кейса.
3. Реализовать страницы: общий список с фильтрами/тегами и отдельная страница кейса.
4. Интегрировать медиа-галереи, отзывы клиентов, блок CTA.
5. Настроить SEO и микроданные (Article/CreativeWork) для кейсов.
6. Обеспечить ISR/SSG и revalidate при публикации новых кейсов.
7. Добавить аналитические события (просмотр кейса, клик по CTA).
8. Написать тесты отображения и проверки корректности данных.
9. Документировать процесс заведения кейсов для контент-менеджеров.

## Контрольные точки
- Портфолио корректно отображается и обновляется из Strapi.
- Аналитика фиксирует вовлечённость пользователей.

## Риски и допущения
- Большие медиафайлы без оптимизации ухудшают производительность.
- Отсутствие регулярного обновления кейсов снижает ценность раздела.
