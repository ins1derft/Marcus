# 5.4 Карточка товара (PDP)

**Статус:** Todo  
**Контекст:** Требуется реализовать галерею, атрибуты, варианты, MOQ и блок нанесения.

## Цель
- Представить подробную информацию о товаре и обеспечить конверсию в запрос/корзину.

## Декомпозиция
1. Определить структуру страницы: галерея, краткое описание, варианты, характеристики, call-to-action.
2. Настроить загрузку данных из Strapi (товар, связанные товары, коллекции, SEO).
3. Реализовать компонент галереи с зумом, превью и поддержкой видео/360 (если требуется).
4. Отобразить вариативность товара (цвет, размер, нанесение), управлять состоянием выбора.
5. Рассчитать и показать MOQ, прайсинг по тиражам, переключатели для нанесения.
6. Интегрировать блок «запросить расчёт» или добавление в корзину.
7. Настроить SEO: canonical, schema.org Product, оглавление для контента.
8. Реализовать отслеживание аналитики (view_item, add_to_cart, request_quote).
9. Покрыть страницу тестами (unit на бизнес-логику, e2e на ключевые сценарии).

## Контрольные точки
- PDP отрисовывает все обязательные данные и корректно работает с вариантами.
- Производительность и Core Web Vitals соответствуют требованиям.

## Риски и допущения
- Отсутствие fallback контента для незаполненных полей ухудшит UX.
- Сложные варианты потребуют оптимизации запросов и кэширования.
