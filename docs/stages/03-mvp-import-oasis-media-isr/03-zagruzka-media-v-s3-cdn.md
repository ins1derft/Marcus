# Загрузка медиа в S3/CDN

**Статус:** Todo  
**Контекст:** Нужно построить пайплайны сохранения файлов и связку с `NEXT_PUBLIC_ASSET_HOST`.

## Цель
- Автоматизировать загрузку и обновление медиафайлов из Oasis в S3/CDN с учётом дедупликации.

## Декомпозиция
1. Проанализировать формат медиа в Oasis: пути, размеры, типы, доступность URL.
2. Определить правила именования и структуру каталогов в S3 (по товарам, категориям, форматам).
3. Реализовать загрузчик файлов: скачивание, проверка хэшей, повторные попытки при сбоях.
4. Настроить дедупликацию и версионирование, хранить метаданные в Strapi (URI, ALT, размеры).
5. Обновить Strapi сущности для хранения ссылок на CDN и fallback вариантов.
6. Реализовать очистку устаревших файлов и синхронизацию при удалении товаров.
7. Настроить обработку изображений (ресайзы, webp) либо через CDN, либо через воркеры.
8. Добавить мониторинг загрузок: счётчики новых файлов, ошибки, размер трафика.
9. Обновить документацию по структуре медиа и интеграцию с фронтендом.

## Контрольные точки
- Медиа доступны по CDN-URL и привязаны к товарам в Strapi.
- Повторные импорты не создают дубликатов и корректно обновляют файлы.

## Риски и допущения
- Ограничения по размеру/скорости загрузок могут требовать очередей и параллельных воркеров.
- Неправильная очистка медиа способна привести к битым ссылкам на фронте.
