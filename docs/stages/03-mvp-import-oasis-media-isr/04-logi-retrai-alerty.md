# Логи, ретраи, алёрты

**Статус:** Todo  
**Контекст:** Требуется настроить лог-репорты и мониторинг ночных запусков импорта.

## Цель
- Обеспечить наблюдаемость ETL-процессов, автоматическое выявление и обработку ошибок.

## Декомпозиция
1. Определить уровни логирования и формат сообщений для ETL (JSON, корелляционные id).
2. Настроить централизованный сбор логов (ELK, Loki, CloudWatch) с фильтрами по джобам.
3. Реализовать систему ретраев: backoff стратегия, максимальное число повторов, DLQ.
4. Настроить мониторинг расписания: проверка успешного выполнения, время выполнения.
5. Добавить алёрты по SLA: отсутствие запуска, превышение ошибок, разрыв в данных каталога.
6. Описать антикризисные процедуры: как перезапускать джобу, восстановление после падения.
7. Провести тесты аварийных сценариев (искусственные ошибки, недоступность S3/Oasis).
8. Задокументировать каналы уведомлений и ответственных лиц.

## Контрольные точки
- Логи ETL доступны в централизованном хранилище и фильтруются по задачам.
- Алёрты приходят не позднее 15 минут после сбоя.

## Риски и допущения
- Чрезмерный объём логов может увеличить стоимость хранения без пользы.
- Ошибки ретраев без DLQ приводят к зацикливанию выполнения.
