# Клиент Oasis API

**Статус:** Todo  
**Контекст:** Требуется реализовать код инкрементальных загрузок, дедупликации и маппинга атрибутов.

## Цель
- Создать устойчивый клиент для Oasis API, обеспечивающий регулярную и надёжную выгрузку данных.

## Декомпозиция
1. Изучить спецификацию Oasis API: авторизация, ограничения, пагинация, фильтры по дате.
2. Выбрать технологию реализации (Node.js сервис, Strapi cron, отдельный worker).
3. Реализовать модуль авторизации и обновления токенов, обработку ошибок сети.
4. Настроить систему инкрементальных загрузок: хранение меток времени, контроль дубликатов.
5. Сформировать маппинг атрибутов Oasis → внутренние атрибуты Strapi, учесть локализации.
6. Реализовать обработку батчей: ретраи, backoff, логирование успешных/ошибочных записей.
7. Написать интеграционные тесты на ключевые сценарии (новый товар, обновление, удаление).
8. Подготовить конфигурацию деплоя: env переменные, расписание запусков, мониторинг.
9. Задокументировать использование клиента и протокол действий при сбоях.

## Контрольные точки
- Клиент успешно загружает данные на тестовом окружении без пропуска записей.
- Настроены метрики (время выполнения, количество обновлений, ошибки).

## Риски и допущения
- Ограничения по rate limit на стороне Oasis могут потребовать очередей и параллелизма.
- Изменение схемы Oasis API потребует оперативного обновления маппинга и тестов.
