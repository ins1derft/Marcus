# GA4 и Tag Manager

**Статус:** Todo  
**Контекст:** Настроить контейнер и базовые события.

## Цель
- Внедрить систему управления тегами и базовую аналитику для отслеживания поведения пользователей.

## Декомпозиция
1. Создать контейнер Google Tag Manager (GTM) или альтернативный инструмент, настроить доступы.
2. Определить минимальный набор тегов: GA4 page_view, scroll, outbound clicks, custom events.
3. Встроить GTM на сайт: добавить скрипты, учесть SSR/ISR особенности.
4. Настроить dataLayer структуру и события от фронтенда.
5. Реализовать механизм управления consent/banner и переключение тегов по согласию.
6. Настроить рабочий процесс публикаций GTM (draft → preview → publish) с ответственными лицами.
7. Провести тестирование через GTM Preview и GA4 DebugView.
8. Документировать схему dataLayer и правила добавления новых тегов.

## Контрольные точки
- Базовые события фиксируются в GA4 без дублирования.
- Согласие пользователя влияет на запуск тегов.

## Риски и допущения
- Неправильно настроенный GTM может замедлить загрузку сайта.
- Отсутствие регламента публикаций приведёт к хаосу в тегах.
