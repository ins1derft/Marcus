# SEO-компоненты

**Статус:** Done  
**Контекст:** В Strapi есть `shared.seo`, требуется внедрить на фронте.

## Цель
- Обеспечить централизованное управление SEO-метаданными через CMS и их корректное использование на фронте.

## Декомпозиция
1. Определить набор полей в `shared.seo` (title, description, og:image, canonical, noindex).
2. Реализовать на фронте утилиты для построения мета-тегов на основе данных из Strapi.
3. Настроить наследование SEO: дефолтные значения, переопределение на уровне страницы.
4. Поддержать OpenGraph, Twitter Cards и schema.org на ключевых страницах.
5. Проверить работу SSR/ISR, чтобы поисковики видели актуальные мета-данные.
6. Документировать процесс обновления SEO-полей для контент-редакторов.
7. Провести аудит с SEO-специалистом и отфиксировать рекомендации.

## Результаты
- SEO-поля управляются через Strapi, фронтенд корректно отрисовывает метаданные.

## Риски и допущения
- Неполные данные в CMS приведут к деградации поисковой выдачи.
- Отсутствие валидации мета-тегов может допустить дублирование title/description.
