# Sitemap, robots.txt и canonical

**Статус:** Todo  
**Контекст:** Реализовать генераторы и мета-теги.

## Цель
- Обеспечить корректное индексирование сайта поисковыми системами.

## Декомпозиция
1. Составить перечень URL, которые должны попадать в sitemap (страницы каталога, PDP, статические страницы).
2. Реализовать генерацию sitemap (динамический API route или build-step), учесть приоритеты и частоту обновления.
3. Настроить robots.txt: разрешённые разделы, disallow для служебных URL, указание sitemap.
4. Включить canonical-теги на всех страницах, определить правила формирования URL.
5. Добавить alternate/hreflang при наличии мультиязычности.
6. Настроить автоматическое обновление sitemap при публикации в Strapi (hook).
7. Провести проверку через Google Search Console/Yandex Webmaster.
8. Задокументировать процесс поддержки и ответственных за обновления.

## Контрольные точки
- Sitemap доступен и соответствует актуальной структуре сайта.
- Robots.txt корректно настроен и не блокирует важные страницы.

## Риски и допущения
- Ошибки в canonical приведут к дублям и потере ранжирования.
- Отсутствие регулярных проверок Search Console может скрыть критичные ошибки индексации.
