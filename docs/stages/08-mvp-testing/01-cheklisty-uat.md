# Чек-листы UAT

**Статус:** Todo  
**Контекст:** Составить сценарии, покрывающие MVP.

## Цель
- Подготовить пользовательские сценарии приёмочного тестирования, подтверждающие готовность MVP.

## Декомпозиция
1. Собрать бизнес-требования и определяющие сценарии (каталог, поиск, корзина, аналитика).
2. Сформировать матрицу UAT: роли пользователей, устройства, браузеры, предусловия.
3. Написать пошаговые кейсы с ожидаемыми результатами и критериями приёмки.
4. Настроить шаблоны протоколов выполнения (Google Sheets, TestRail, Notion).
5. Согласовать чек-листы с заказчиком и командой разработки.
6. Определить расписание UAT, ответственных за выполнение и канал обратной связи.
7. Подготовить среду для UAT: доступы, данные, инструкции по логированию дефектов.
8. Обновлять чек-лист по мере изменений требований и релизов.

## Контрольные точки
- Чек-листы покрывают ключевые бизнес-сценарии и подписаны заказчиком.
- Есть процесс фиксации и обработки найденных дефектов.

## Риски и допущения
- Неполные сценарии не выявят критичных дефектов перед запуском.
- Без управления версиями чек-листа возможны разночтения между релизами.
