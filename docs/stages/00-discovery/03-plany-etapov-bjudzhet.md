# Планы этапов и бюджет

**Статус:** Done  
**Контекст:** ТЗ содержит трудозатраты по спринтам и платежную модель.

## Цель
- Превратить высокоуровневые требования в план работ с оценками, распределёнными по этапам и платежным вехам.

## Декомпозиция
1. Снять ограничения по срокам и бюджету с заказчиком, зафиксировать формат отчётности.
2. Собрать входные данные: объём фич, доступность команды, внешние зависимости.
3. Определить этапы MVP и роста, сформировать критерии завершения каждого этапа.
4. Оценить трудозатраты по задачам, используя экспертные оценки и аналогии.
5. Сбалансировать план по спринтам: упорядочить задачи по приоритету и зависимостям.
6. Определить платёжные вехи, привязанные к контролируемым результатам.
7. Подготовить диаграмму или таблицу распределения ресурсов (часы/специализации).
8. Согласовать план с заказчиком, учесть обратную связь, зафиксировать изменения.
9. Обновить Roadmap и связанные документы, уведомить команду о финальной версии.

## Результаты
- Утверждённый поэтапный план с бюджетом, используемый для контроля исполнения.

## Риски и допущения
- Возможные сдвиги сроков требуют оперативного пересмотра бюджета.
- Приоритеты заказчика могут меняться, что влияет на распределение задач по этапам.
